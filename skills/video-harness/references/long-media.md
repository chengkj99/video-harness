# 长素材、主题拆解与恢复

读取时机：长分享、课程、多文件连续录制、拆多条短片或资源受限。

1. 建素材清单，明确是否为连续录制、不同机位或独立主题。多机位不自动当作按文件名顺序拼接。
2. 先做语音样本，记录模型、语言、词表和识别错误。磁盘/内存有限时只提取分析所需音频；脚本逐块生成16kHz单声道WAV，无需整段高清视频驻留内存。
3. 默认核心块600秒、窗口边界重叠2秒。每词恢复源绝对时间，以词中点归属唯一核心块，减少边界重复；原块结果仍保留。跨块词不清或近重复应回查，不能宣称此算法消除所有ASR误差。
4. 查看全部块的主题覆盖，建立主题地图。缺失块、没有识别到的语音和无声段要区分；静音不是可凭空补全文字的理由。
5. 每个候选片段记录：源文件/起止、问题、主张、依据、例子、结论、前后依赖、可删口头语及风险。避免截掉限定词，或把反问剪成肯定。
6. 优先建议内容能自洽的少量成片，标注短视频/中视频适合度与时长；不默认“每个主题必须压到60秒”。用户确认后才批量渲染。

## 代理选择

高分辨率、大体积或解码慢时用prepare --proxy生成最长边720、15fps代理供浏览。代理仅用于分析，最终按源文件剪辑。代理时间起点与源文件一致；不把代理的帧数当成源帧数。若源为特殊时间码/异常起始PTS，抽样核对音画同步后再大批量制作。

## 恢复与变更

同一转写命令会跳过已完成块；`--max-new-chunks 1`可用于短流程验证或有意分批，不是完成全片。重复调用会继续未完成块。修改模型、词表、块大小或源文件会使用新缓存。

长视频不能只以small模型转写判断准确性。先比较原声/现有稿件；必要时请求更大模型，但不要无授权调用外部收费转写。双人同时说话、口音和远场收音应保留疑点，v1不提供说话人分离。

时间轴改变时，利用字幕source锚点重新计算新成片时间；用户确认文字优先保留。区间横跨新切口、重复使用同一源片段或字幕缺少源锚点时逐项处理，不能按全片统一平移猜测。
