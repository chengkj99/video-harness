# 双比例故事化封面规范

默认同时交付竖版 **3:4** 和横版 **4:3**，推荐尺寸分别为 1500×2000 与 1600×1200。横版封面不再默认使用 16:9。视频画幅独立配置，不能因封面比例改变而裁切成片。用户明确指定其他尺寸时遵从该要求，并记录用途。

## 设计流程

1. 从已确认剪辑稿提炼观众的具体困惑、转变或收获。标题短、可读、有吸引力，不能夸大结论。封面不是字幕全文。
2. 使用有来源、经用户指定的讲者照片或视频帧，确认本人身份。没有头像时先交付文字草稿，不生成一个陌生人冒充讲者。
3. 默认采用故事化编辑拼贴：深蓝/蓝灰底、米白文字、暖金重点、轻度撕纸质感；人物与一个相关场景构成叙事。例如镜头前紧张与真实交流，思考与不同人生。场景是概念插画时不能伪装成真实事件证据。品牌名与期数需配置，不内置任何用户姓名。
4. 竖版和横版分别构图。横版可左标题右人物，竖版可上标题下人物；根据内容调整。保持人物比例，不能把一版拉伸成另一版，也不能靠裁切损失标题、脸部或必要场景。
5. 创意绘制/修改使用可用的图像生成工具；提供真实参考图、精确文字、画幅和不变项。工具不可用时明确交付文字占位稿，不能声称已完成故事化封面。
6. 在缩略图尺寸检查标题辨识度、留白、脸部、眼镜、手腕和手指。手臂归属必须清楚，避免多手、错位手或不自然交叉。复杂姿势优先简化为一只自然可见的手。逐字检查中文、姓名、期数。
7. 验证实际像素：竖版 width×4 == height×3；横版 width×3 == height×4。最终资产与两种比例、提示词、来源和校验记录关联，保留旧版本。封面需随每条视频、描述、标签一起交付。

这些是本工作流的设计默认值，不代表所有平台的硬性要求。发布前检查具体平台预览和遮挡。

## 本地打包接口

`copy.json` 的 `cover_sizes` 默认值为 `{ "portrait": [1500, 2000], "landscape": [1600, 1200] }`。`package` 输出 `cover-portrait.svg/png` 与 `cover-landscape.svg/png` 两套文字设计草稿，同时保留旧的 `cover.svg/png` 主封面供兼容。

已有项目没有 `cover_sizes` 时也生成默认双比例封面；旧 `cover_size` 继续控制主封面。显式配置的 portrait、landscape 必须分别为 3:4、4:3。更改旧项目配置需由制作步骤明确执行，不暗改既有文件。

内置 SVG/Pillow 仅产生文字排版，**不自动生成头像或故事场景**。故事化封面应通过图像工具完成，并在实际交付时替换文字设计草稿、更新清单和校验；不得把占位图描述为最终故事化封面。
