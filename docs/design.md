# Video Harness 设计

日期：2026-10-24。范围由用户确认：独立仓库，Codex 优先，第三条分享视频验证。

## 产品目标

中文口播、分享、访谈的本地内容生产：分析 → 选题确认 → 剪辑稿确认 → 编译时间轴 → 成片复核 → 发布包。原始音视频只读。AI 做语义判断，程序执行版本、依赖、媒体边界和审批检查。不自动发布。

## 第一版边界

- Python 标准库实现状态、审批、导入、句级删改、时间轴编译、CLI 和本地审阅页。
- v0.2 将 talking-head-editor 媒体代码收入仓库，作为默认内置后端维护；保留旧工程显式外部后端接口。Python 包和 Codex 插件均携带媒体脚本及默认样式。后端升级使旧构建失效。
- 支持已有工程导入，也支持已有源锚点转写创建工程。新素材的转写/初始化由配置的后端执行；选题和语义校对由 Codex 执行。
- 首版句级删除；不假装支持可靠词级消除拖音。句内剪切需先提供经过回听的精确边界。
- 粗剪预览可在文字确认前生成用于审阅，但必须标为 draft；正式导出必须具备当前选题、剪辑稿和成片确认。
- 封面支持可配置尺寸的文字设计 SVG/可选 PNG，不声称某个比例通用于所有平台。描述和标签由 Agent 编写，程序打包。
- 不含自动发布、账号系统、多机位、声音克隆、复杂动效、自动全片语义验收。

## 资产与依赖

原始快照（project/plan/captions/style）→ 选题 → 剪辑稿（稳定句 ID、说话人、原话、展示文字、源区间、删留）→ 编译工程 → 渲染结果 → 发布包。

选题审批绑定选题哈希；剪辑稿审批绑定选题和剪辑稿；成片审批绑定实际文件、编译输入、后端指纹。封面/描述变更不让视频重新渲染。任何源文件身份变化、上游改变或输出缺失都阻止正式交付；旧输出保留。

源身份记录路径、大小、mtime 与首尾采样 SHA256（并非全量校验）；需要严密归档时另做全量哈希。项目状态使用原子替换，进程锁避免并发覆盖；事件日志追加；直接手改文件也通过状态重新计算依赖识别。

## 编辑语义

- 原话只读；改错字更新展示字幕，不合成新语音。自由重写需补录或编辑说明。
- 删除句子对应删除其源时间区间，保留其余原始选段中的停顿/笑声/上下文；禁止简单拼接每句语音而吞掉句间情绪。
- 时间轴按帧量化，字幕由源锚点重新映射；章节按旧输出位置反查源位置再映射；删去章节起点时顺延到下一保留片段或去掉。
- 稳定 ID 不重新编号；删除记录可恢复。首版不支持跨片段重排，需修改明确的源选段后重新审阅。

## Codex 接入

仓库提供 .codex-plugin/plugin.json 和 skills/video-harness，外加本机技能链接安装脚本作为可验证的兼容入口。插件登记按本机 Codex 支持方式执行，不直接篡改插件缓存/全局注册表。核心 CLI 不依赖 Codex，其他宿主以后增加入口。

## 审阅体验

本地 loopback HTTP 服务：显示完整文字稿、标识说话人、点击源时间回看、修改字幕、删留、记录明确确认。请求使用随机会话令牌；只服务声明素材，支持 Range，禁止任意文件读取。修改带预期版本，过期页面拒绝覆盖。网页仅供用户操作，不让 Agent 自动点击确认。CLI 的聊天确认也必须有针对当前展示版本的用户原话。

## 数据与测试

代码、模板、脱敏合成测试可入 Git；真实媒体、项目、用户审批证据与输出位于仓库外。测试覆盖越界/重复 ID、删除后字幕映射、审批失效、旧版本冲突、封面变化不触发渲染、源变更、草稿不冒充交付。真实第三条单独报告听审与技术验证范围。
