# v0.1 实施计划

1. 建立 Python CLI、项目 schema、原子状态与事件日志，加入源身份校验。
2. 导入第三条旧工程，保留来源、既有删改、说话人与字幕不确定状态，生成可读审稿文件。
3. 实现选题/剪辑稿/成片三阶段版本确认，状态与过期检测；确认不能由“已导入”推断。
4. 实现句级删除与字幕纠错，按源锚点编译后端工程，保留原计划中未删除的声音和画面。
5. 适配本地 talking-head-editor，生成草稿预览/正式渲染、技术验证，记录执行日志和后端指纹。
6. 增加本地审阅页及 CLI 导出、封面和发布文案打包；草稿发布包可查看，正式包须通过确认。
7. 制作 Codex 插件入口、安装与恢复说明；验证技能可发现，不能声称未验证的新会话已加载。
8. 标准库单元/集成测试、合成媒体端到端、第三条实际工程验证。用户未回复时只推进非审批依赖任务，明确真实项目停留节点。

验收：敏感句不能恢复；源视频不修改；稳定字幕 ID；修改字幕使旧确认失效；只改文案不重新渲染；断点恢复读取文件状态；正式交付不得绕过用户确认；包内视频/字幕/封面/描述齐全。

待后续：可靠词级时间对齐、拖音建议与逐处预览、复杂章节重排、更多平台模板、第二宿主。不上来实现通用 DAG 引擎。

## 实施结果（2026-10-24）

1–7 已实现。第 8 步的核心/HTTP 测试、合成媒体全流程、第三条真实渲染及正式交付包均已验证，见 validation.md。
真实第三条已取得用户成片确认并生成正式本地交付包；确认记录和项目保存在仓库外，不随代码上传。
